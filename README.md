# Тесты класса BooksCollector

В проекте реализованы автоматизированные тесты класса `BooksCollector` с использованием библиотеки `pytest`.

## Проверяемые сценарии

### Добавление книг

- добавление двух книг в коллекцию книг;
- отклонение книги с пустым названием;
- отклонение книги, название которой содержит больше 40 символов;
- добавление книги с названием длиной ровно 40 символов;
- проверка, что добавленная книга не имеет жанра по умолчанию.

### Работа с жанрами

- установка валидного жанра для книги;
- отклонение невалидного жанра;
- получение списка книг с определённым жанром;
- получение пустого списка, если книг с этим жанром нет;
- получение текущего словаря жанров - `books_genre`;
- проверка книг, подходящих для детей;
- проверка отсутствия в выводе книг с возрастным рейтингом в списке детских книг.

### Работа с избранным

- добавление книги в избранное;
- предотвращение повторного добавления одной и той же книги;
- удаление книги из избранного;
- получение списка избранных книг;
- проверка работы со списком избранного, содержащим одну или несколько книг.
